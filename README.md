# ICTD Lab GSI Project

ICTD Lab will create an integrated platform for geospatial data collection, visualization and app development. It will play a role in spotting cities and will support Bangladesh in local development planning, disaster management, planning, situational awareness and security.  ICTD Lab is a GIS Project and a partner of the Information and Communication Technology Directorate (ICTD) of Bangladesh, a global research, training and service provider of Geographic Information Systems (GIS). The objective of this project is to ensure the use of GIS technology in the private and public sectors for the acquisition of key data, formulation of discussions and development of digital services.



# How to set up the project

- Clone the git 

```
git clone

npm install

npm run dev
```
